Overview

BlackNet is a distributed network designed to route traffic through volunteer-operated relay nodes using layered encryption and multi-hop routing.

◆ No Centralized Infrastructure

Distributed relay network operated by volunteers worldwide, eliminating single points of failure.

⟳ Volunteer-Based Architecture

Anyone can contribute to the network by running a relay node with minimal hardware requirements.

🔐 Multi-Hop Encrypted Routing

Traffic encrypted at each hop through multiple relays, obscuring routing information at each layer.

⚖ Network Consensus

Network decisions made through distributed consensus without centralized authority.

🌐 Privacy-First Design

Integrated browser and network stack designed from the ground up for privacy.

⚡ Lightweight & Efficient

Optimized routing and relay implementations for practical performance without sacrificing security.

Partial Routing Data

Each relay only knows the previous and next hop. No single relay can see the complete circuit path or final destination.

Layered Encryption

Traffic is encrypted at each hop. Each relay removes one layer of encryption, passing the payload forward.

Circuit Rotation

Circuits are automatically rotated periodically and on demand, changing the relay path to prevent correlation attacks.

Metadata Separation

BlackNet architecture separates connection metadata, timing information, and content across multiple relays.

BlackNet Browser

A hardened privacy browser engineered to route all traffic through BlackNet Core by default.

✓ Based on Firefox ESR

Hardened privacy configuration built on Firefox Extended Support Release for stability and security updates.

✓ Forced BlackNet Routing

All traffic automatically routed through BlackNet Core with no option to disable, ensuring consistent privacy.

✓ Anti-Fingerprinting Protections

Disabled JavaScript fingerprinting vectors, spoofed user-agent rotation, and canvas/WebGL rendering restrictions.

✓ DNS Leak Prevention

All DNS queries forced through BlackNet relays with encrypted DNS-over-HTTPS fallback.

✓ Circuit Diagnostics Panel

Built-in diagnostics dashboard showing active relay circuit, hop information, and performance metrics.

✓ Default Privacy Settings

Tracking protection enabled by default, no third-party cookies, automatic HTTPS enforcement.

Security Model

Understanding BlackNet's privacy architecture and threat model.

Privacy Through Distribution

BlackNet improves privacy by distributing traffic across multiple encrypted relay hops and separating knowledge between nodes in the network.

  • ▶ No Single Observer: Individual relays cannot correlate users with destinations
  • ▶ Encryption Layers: Each hop has a different encryption key, preventing plaintext leakage
  • ▶ Distributed Trust: You don't need to trust any single relay operator
  • ▶ Metadata Isolation: Timing, destination, and content information spread across the network

⚠ Important Disclaimer

No system guarantees absolute anonymity. Users should understand their threat model and limitations. BlackNet provides privacy improvements through technical design, but cannot protect against:

  • ✗ Compromised client-side malware
  • ✗ Compromised operating system or firmware
  • ✗ Attacks from global adversaries with massive traffic analysis capabilities
  • ✗ User behavior patterns that reveal identity independently

Always consider your specific threat model when using any privacy tool.
