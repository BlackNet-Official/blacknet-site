Overview

BlackNet is a distributed network designed to route traffic through volunteer-operated relay nodes using layered encryption and multi-hop routing.

Partial Routing Data

Each relay only knows the previous and next hop. No single relay can see the complete circuit path or final destination.

Layered Encryption

Traffic is encrypted at each hop. Each relay removes one layer of encryption, passing the encrypted payload forward.

Periodic Circuit Rotation

Circuits are automatically rotated periodically and on demand, changing the relay path to prevent correlation attacks.

Metadata Separation

BlackNet architecture separates connection metadata, timing information, and content across multiple relays to reduce tracking.

Security Model

Understanding BlackNet's privacy architecture and threat model.

Privacy Through Distribution

BlackNet improves privacy by distributing traffic across multiple encrypted relay hops and separating knowledge between nodes in the network.

  • No Single Observer: Individual relays cannot correlate users with destinations
  • Encryption Layers: Each hop has a different encryption key, preventing plaintext leakage
  • Distributed Trust: You don't need to trust any single relay operator
  • Metadata Isolation: Timing, destination, and content information spread across the network
⚠ Important Disclaimer:

No system guarantees absolute anonymity. Users should understand their threat model and limitations. BlackNet provides privacy improvements through technical design, but cannot protect against:

  • Compromised client-side malware
  • Compromised operating system or firmware
  • Attacks from global adversaries with massive traffic analysis capabilities
  • User behavior patterns that reveal identity independently

Always consider your specific threat model when using any privacy tool.
